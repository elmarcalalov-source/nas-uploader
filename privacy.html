Privacy Policy – NAS Uploader

Last updated: 6 November 2026

NAS Uploader uses the YouTube Data API only to upload videos to the owner's own YouTube channel and to read the channel name for a connection check. It requests the scopes youtube.upload and youtube.readonly.

The access token is stored only on the owner's own server. No data is shared with, sold to, or sent to any third party. No personal data of other users is collected.

Access can be removed at any time at Google Account permissions.

The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is subject to the YouTube Terms of Service and the Google Privacy Policy.
